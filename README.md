# Rytm

Aplikacja webowa, która wgrywa CSV z wyciągu bankowego (ING Bank Śląski, PLN) i pokazuje, gdzie cicho ucieka pieniądz: wykrywa powtarzalne wzorce wydatków (stałe: sprzedawca + podobna kwota; częste: sam sprzedawca), pozwala ustawić próg na wzorcu i oznacza nadwyżkę jako zbędną.

Projekt zaliczeniowy 10xDevs 4.0 (blok Builder). Decyzje i zapis brainstormingu: `BRAINSTORMING-projekt-zaliczeniowy.md`. Wymagania kursu: `PROJEKT-ZALICZENIOWY-wymagania.md`.

Następny krok: `/10x-init` → `/10x-shape` (prompt w sekcji 9 pliku brainstormingu).
