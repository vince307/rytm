# design/

Źródło prawdy dla UI/UX projektu Rytm. Kontrakt, reguły użycia, konflikty i rejestr braków:
**`context/foundation/design-kit.md`**.

- `rytm-os/react-kit/` — handoff do React (assets, tokeny, copy, trasy) — główne źródło dla implementacji
- `rytm-os/brand-pack/` — pakiet identyfikacji z kartą stylu i eksportami PNG
- `rytm-os/prototype/` — działający prototyp HTML (otwórz `index.html`) — jedyna specyfikacja layoutów

Nie edytuj tych plików ręcznie: nowe wersje dostarcza autor projektu, a braki zgłasza się w rejestrze w `design-kit.md`.
