# Rytm — Oś: prototyp HTML

To jest klikalny, statyczny prototyp z hash routingiem. Uruchom `index.html` przez lokalny serwer HTTP (np. `python3 -m http.server 4173 -d prototype`) i otwórz `http://localhost:4173/`.

Podglądy każdego stanu są w `views/`; strona `views/index.html` zawiera katalog widoków. Prototyp używa wyłącznie danych syntetycznych i nie przetwarza prawdziwych plików CSV.
